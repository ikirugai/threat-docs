# T.H.R.E.A.T. methodology

This repository hosts the public methodology page for T.H.R.E.A.T., the
browser-based HVM and blast assessment tool by ikirugai ltd.

Read it at **https://ikirugai.github.io/threat-docs/** (or
[`index.md`](./index.md) on GitHub).

**Status, 19 October 2026:** version 3.40 (engineering model unchanged
since 3.36), in the tool's own identity (`_layouts/default.html`,
`assets/css/site.css`, fonts under the SIL Open Font Licence in
`assets/fonts/`). The page describes the
engineering basis, the standards followed, what is calibrated, the
validation results and the limitations. It replaces the withdrawn v3.17
reference. The full as-built technical reference (every constant and its
source, and the complete calibration, validation and sensitivity data)
is kept in the private main repository and given to independent
reviewers on request.
